Solids: cube, cuboid, pyramid, prism, cylinder, sphere සහ cone. Surface area සහ volume සඳහා අදාළ formula තෝරා combined solids ගණනය කරන්න.

Fractional error = absolute error / measured value
Percentage error = fractional error × 100%

Competency 3 · Pythagoras relationship

Right-angled triangle: a² + b² = c² (c = hypotenuse)

සෘජුකෝණී ත්‍රිකෝණයක කර්ණයේ වර්ගය අනෙක් පාද දෙකේ වර්ග එකතුවට සමාන වේ. Converse එකෙන් දිග තුනක් ලබාදී a²+b²=c² නම් ත්‍රිකෝණය right-angled බව තීරණය කළ හැක.

Example: පාද 6 cm සහ 8 cm නම් කර්ණය √(36+64)=10 cm.

Competency 7 · Trigonometric ratios

Angles degrees සහ radians දෙකෙන් මනිනු ලැබේ.

180° = π radians   |   θ (radians) = θ° × π/180

Right triangle එකක:

sin θ = opposite / hypotenuse
cos θ = adjacent / hypotenuse
tan θ = opposite / adjacent = sin θ / cos θ
sin²θ + cos²θ = 1

Angles of elevation/depression practical height-distance problems සඳහා යොදාගන්න. ත්‍රිකෝණයක පැති දෙක සහ අතර කෝණය දී ඇති විට:

Competency 19 · Cartesian plane

Coordinates (x,y) භාවිතයෙන් points දෙකක් අතර දුර සහ midpoint සොයයි.

Distance = √[(x₂−x₁)²+(y₂−y₁)²]
Midpoint = ((x₁+x₂)/2, (y₁+y₂)/2)

Straight line equation:

y = mx + c

m gradient එකත් c y-intercept එකත් වේ. Parallel lines වල gradients සමානයි. Perpendicular lines සඳහා m₁m₂ = −1 (gradient දෙක නිර්වචනය කළ හැකි අවස්ථාවල).

Competency 19 · Linear and quadratic functions

Linear function එකක graph එක straight line එකකි. y=mx+c හි m වෙනස් කළ විට slope වෙනස් වන අතර c වෙනස් කළ විට y-intercept වෙනස් වේ.

Quadratic function:

y = ax² + bx + c
Turning point x-coordinate = −b/(2a)

a>0 නම් parabola එක ඉහළට විවෘත වේ; a<0 නම් පහළට විවෘත වේ. x=−b/(2a) substitute කර turning point එකේ y-coordinate සොයන්න. Rough sketch එකේ axis of symmetry සහ intercepts සලකුණු කරන්න.

Competency 20 · Descriptive statistics

Central tendency: mean, median, mode. Ungrouped data සහ grouped data සඳහා mean/median ක්‍රම වෙන්කර ඉගෙන ගන්න. Σ සංකේතය values එකතුව දැක්වීමට යොදාගනී.

Mean = Σx / n   |   Grouped mean = Σfx / Σf

Median යනු අනුපිළිවෙළට සකස් කළ දත්තවල මැද අගයයි. Mode යනු වැඩිම වාර ගණනකින් පෙනෙන අගයයි. Frequency distribution, cumulative frequency සහ percentage cumulative frequency curves සකස් කර අර්ථකථනය කරන්න.

Measures of distribution

Range = maximum − minimum
Interquartile range (IQR) = Q₃ − Q₁

Quartiles දත්ත කාණ්ඩ හතරකට බෙදන අගයන් වේ. Range සහ IQR භාවිතයෙන් දත්ත පැතිරීම (spread) විස්තර කරන්න. Grouped data සඳහා syllabus/ගුරුවරයා ලබාදෙන formula භාවිත කර ගණනය පුහුණු කරන්න.

Practice questions

  4. (2,3) සහ (8,11) අතර දුර සහ midpoint සොයන්න.
  5. y=2x+5 හි gradient සහ y-intercept දක්වන්න.
  6. Data set එකක mean, median, mode, range සහ IQR සොයන්න.
