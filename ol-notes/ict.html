ICT

O/L Information and Communication Technology: computer systems, data, networks, digital productivity, algorithms, programming and web basics.

මෙම පිටුව O/L Grade 10–11 මට්ටමේ මූලික සංකල්ප සිංහලෙන් පැහැදිලි කර English technical terms සමඟ සකස් කර ඇත. පාඩම් අනුපිළිවෙළ ඔබගේ පාසල් පෙළපොත සහ ගුරු උපදෙස් සමඟ සසඳන්න.
Computer systemsDataNetworksDigital productivityAlgorithmsWeb and safety

1. Computer systems

Computer system එකක් hardware, software, data, users සහ procedures එකතුවකි. Hardware යනු ස්පර්ශ කළ හැකි physical components; software යනු instructions/programs වේ.

ComponentFunction
CPUInstructions process කරයි; ALU සහ Control Unit ඇතුළත් වේ.
RAMදැනට ක්‍රියාත්මක programs/data තාවකාලිකව තබයි.
StorageFiles දිගුකාලීනව තබයි (HDD/SSD).
Input devicesKeyboard, mouse, scanner, microphone.
Output devicesMonitor, printer, speakers.

Operating system එක hardware සහ applications අතර සම්බන්ධතාව පාලනය කරයි. Utility software සහ application software අතර වෙනස දැනගන්න.

2. Data representation

Data යනු raw facts; processing කළ විට meaningful information බවට පත්වේ. Binary number system එක base 2 වන අතර digits 0 සහ 1 භාවිත කරයි.

1 byte = 8 bits
Binary place values: 1, 2, 4, 8, 16, 32, ...

Files සහ folders, file extensions, storage capacity units, data validation සහ backups අධ්‍යයනය කරන්න. Accurate, relevant, complete සහ timely information වල ලක්ෂණ හඳුනාගන්න.

3. Computer networks and internet

LAN යනු සීමිත ප්‍රදේශයක network එකකි; WAN විශාල භූගෝලීය ප්‍රදේශ සම්බන්ධ කරයි. Router networks අතර data යොමු කරයි; switch local network එකක devices සම්බන්ධ කරයි; modem communication link එකකට සම්බන්ධ කරයි.

Internet සහ World Wide Web එකම දෙයක් නොවේ. Browser එක web pages පෙන්වයි; search engine එක information සොයයි. URL, domain name, IP address සහ basic network protocols හඳුනාගන්න.

4. Digital productivity

Word processor: document formatting, tables, page layout, headers/footers. Spreadsheet: cells, rows, columns, formulas, functions, charts සහ sorting/filtering. Presentation software: slide layouts, readable text සහ suitable visuals.

Spreadsheet examples: =SUM(B2:B10)
=AVERAGE(C2:C10) · =MAX(D2:D10) · =MIN(D2:D10)

File naming, saving formats, print settings සහ collaborative editing ආරක්ෂිතව භාවිත කරන්න.

5. Algorithms and programming

Algorithm යනු ගැටලුවක් විසඳීමට අනුපිළිවෙළින් සකස් කළ පැහැදිලි පියවර මාලාවකි. Flowchart symbols: oval—Start/End; parallelogram—Input/Output; rectangle—Process; diamond—Decision.

START ↓ INPUT mark ↓ mark >= 50 ? ↙ YES NO ↘ OUTPUT Pass OUTPUT Try again ↘ ↙ END

Sequence, selection (if/else) සහ iteration (loops) හඳුනාගන්න. Variables, constants, operators, input, output සහ debugging මූලික සංකල්ප පුහුණු කරන්න.

6. Web, ethics and cybersecurity

HTML page structure, headings, paragraphs, links, images සහ lists හඳුනාගන්න. Strong unique passwords, multi-factor authentication, updates, antivirus, backups සහ privacy settings භාවිත කරන්න.

Phishing, malware, cyberbullying, plagiarism සහ copyright infringement හඳුනාගෙන වගකීමෙන් digital technology භාවිත කරන්න.
